# 接口规格文档模板

> 生成接口文档时，严格按此模板结构输出。模板中 `{...}` 为占位符，根据实际内容替换。

## 章节白名单（只允许生成以下顶级 `##` 章节，按此顺序）

| # | 章节名 | 何时存在 | 由谁写 |
|---|--------|---------|--------|
| 1 | 需求概要 | 必存 | tapd-to-doc Phase 5 |
| 2 | 业务流程 | 必存 | tapd-to-doc Phase 5 |
| 3 | 接口清单 | 必存 | tapd-to-doc Phase 5 |
| 4 | 接口详情 | 必存 | tapd-to-doc Phase 5 |
| 5 | 数据库变更 | 无 DB 变更则省略 | tapd-to-doc Phase 5 |
| 6 | 代码改动清单 | 必存 | tapd-to-doc Phase 5 |
| 7 | BE 自决事项 | 无自决则省略 | tapd-to-doc Phase 5 |
| 8 | 协调事项 | 无跨模块协调则省略 | tapd-to-doc Phase 5 |
| 9 | 澄清记录 | 有 Q&A 则存 | tapd-to-doc Phase 5 |
| 10 | 变更记录 | 必存 | tapd-to-doc Phase 5（每次写表头 1 行） |

## 章节黑名单（禁止生成；命中即 reviewer SLM-08 BLOCK，不可 force-proceed）

| 禁用章节模式 | 禁用理由 | 闭环结论去处 |
|-------------|---------|-------------|
| `## v[N] 对齐 Figma 状态机偏差说明` / `## v[N] 偏差点` | 过程章节，闭环后已无价值，污染规格阅读 | 业务规则段直接按当前态单义重写，不留偏差说明 |
| `## BE 反向质疑` / `### USQ-0X.X` / 任何反向质疑段 | 反向质疑只走 TAPD 评论，不进 spec | ship 后在「决策与踩坑」留一行 `[decision] BE 就 X 反向质疑 PM #XXX，PM 二次答 Y，结论合入 BE-N` |
| `## 跨模块影响传播` / `### v[N] 跨模块影响传播` | 已 propagate 的表无价值，未 propagate 的属"协调事项" | 未 propagate 的合入「协调事项」；已 propagate 的整段删除 |
| `## 历史立场链` / `### 历史立场归档` / `### vN 候选方案（已废止）` | 立场演变属 git log，不属当前态规格 | 立场翻转记录归 git log；当前态结论合入 BE 自决 |
| `## 门禁阻断说明` / `## 双门禁评估` / `### Phase 6.0 门禁状态` | 流程过渡态，ship 后归零 | 整段删除 |
| 同一文档内多份 `### v[X.Y.Z] 自检（...）` 并存 | 自检不累积（R5），仅保留当次 | 仅保留最新 1 份，旧的整段删除 |
| 主体章节内出现 `(翻转|取消降级|降级|收敛)` 立场切换语句 | 立场切换属过程审计 | 仅保留当前结论，状态切换链归 git log |

**核心原则**：文档描述的是**此刻**应该怎么实现，不是怎么演变到此刻的。演变路径归 git log / TAPD 评论 / `决策与踩坑`。

## 数据库变更

> 如果本次需求无任何数据库变更，删除本章节。
>
> **R3 规则**：只保留**终态** CREATE TABLE；增量 ALTER 走 migration 文件名引用，不在 spec 内粘贴 ALTER SQL 全文。当本次变更是对已有表加字段时，重写表的 CREATE TABLE 终态（含新字段），ALTER 脚本放 migration 文件。

### 新增/变更表（终态 CREATE TABLE）

#### `table_name` — 表说明

```sql
CREATE TABLE `table_name` (
  `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
  `field_a`     VARCHAR(64)  NOT NULL                COMMENT '字段说明',
  `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `deleted`     TINYINT      NOT NULL DEFAULT 0      COMMENT '逻辑删除，0-正常 1-已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表说明';
```

| 字段 | 类型 | 可空 | 默认值 | 说明 |
|------|------|:----:|--------|------|
| id | BIGINT | 否 | 自增 | 主键 |

### Migration 文件

- `migration/{table}-ddl.sql` — 终态 CREATE TABLE（首次部署）
- `migration/{table}-vX.X.X-alter.sql` — 增量 ALTER（已落盘环境升级用，由 migration 文件单点维护，spec 不重复粘贴 ALTER 全文）
