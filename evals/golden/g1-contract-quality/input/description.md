# 需求素材 — 用户积分签到

产品希望上线「每日签到得积分」功能：

- 用户每天可签到一次，签到得 10 积分
- 连续签到 7 天额外奖励 50 积分，中断则连续计数归零
- 已签到当天再次签到应提示「今日已签到」，不重复发积分
- 积分可在个人中心查看余额与明细

（口述补充）积分是否可过期、能否兑换商品，PM 说"这期先不做，后面再定"。
